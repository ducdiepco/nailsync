# NailSync

Android nail salon point-of-sale app built with Kotlin and Jetpack Compose.

## Backend

API backend: **https://github.com/ducdiepco/nailsync-api**

## Stack

- Kotlin, Jetpack Compose, Material3
- MVVM + Clean Architecture (feature-based)
- Hilt, Room, Navigation Compose, StateFlow

## Features

- Ticket queue with adaptive two-pane layout (tablet/phone)
- Ticket detail with embedded service catalog and category tabs
- Customer accounts (create, edit, search)
- Technician assignment per service
- Checkout with tip presets
- Combine tickets (merge services, cancel source)
